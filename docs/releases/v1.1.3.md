VoiceFlow now supports local and cloud dictation, with faster model loading and a smoother recording notch.

### Downloads

- **VoiceFlow-v1.1.3-Setup.exe** — recommended Windows x64 installer.
- **VoiceFlow-v1.1.3-win-x64.zip** — portable version; extract the entire folder and run VoiceFlow.exe.
- **SHA256SUMS.txt** — checksums for both packages.
- **INSTALL.txt** — installation and upgrade notes.

Close VoiceFlow from its tray before upgrading. Both packages include .NET. Model weights and optional CPU/GPU backends download on first use. The installer is unsigned.

### Local model notes

Whisper GPU uses Vulkan on compatible AMD, Intel, and NVIDIA hardware. Bark GPU requires a compatible NVIDIA GPU and CUDA driver 12.6 or newer; use CPU on AMD. Local Whisper's native backend requires Windows 11, AVX2/FMA/F16C, and the Visual C++ 2022 x64 redistributable.

Bark expands to several GB of RAM; its optional decoded cache uses about 2.5 GB of extra disk. First setup/cache creation takes longer. Models release after 15 idle minutes unless Keep model ready is enabled.
